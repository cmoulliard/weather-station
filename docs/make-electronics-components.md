# Components for "Make: Electronics" (3rd ed. — Charles Platt)

> Component list for the 30 experiments, **excluding** what is already included in the Freenove FNK0020 kit.

## Already included in the Freenove FNK0020

- Breadboard
- LEDs (red, green, blue, yellow, RGB)
- Resistors: 220Ω, 1KΩ, 10KΩ
- Potentiometer 10KΩ
- Push buttons
- Active + passive buzzer
- Jumper wires
- 7-segment display
- Capacitors (a few values)
- Transistors (a few)
