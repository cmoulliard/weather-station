# draw.io library — breadboard electronics

`breadboard-electronics.xml` is a draw.io library with breadboard parts (breadboard, perfboard,
resistors, diodes, LEDs, button, relay HK4100F, 9 V battery, ESP32 DevKit, …) and coloured wires.

![demo](demo-relay-led.png)

## Open the library

draw.io desktop or app.diagrams.net → **File ▸ Open Library from ▸ Device…** → select
`breadboard-electronics.xml`. A new palette appears in the left sidebar (it stays there after a restart).

## Build a diagram

1. Turn on the grid: **View ▸ Grid**, grid size **10** or **20** px.
2. Drop a **breadboard**, then drop parts onto it. All pins use a **20 px pitch (= 1 hole = 2.54 mm)**,
   so parts snap straight onto the holes.
3. Drag a **wire** from the palette, then drag each end onto a pin or a hole. A blue ✕ shows each connection
   point. The wire stays attached when you move the part.
4. To add a bend in a straight wire, drag the small handle in the middle of the wire. To switch to automatic
   right-angle routing, use **Format ▸ Arrange ▸ Waypoints ▸ Orthogonal**. Crossing wires are drawn with a small hop.
5. Change a part's label (e.g. `220 Ω`) by double-clicking it.

Parts can be resized and keep their proportions (`aspect=fixed`), and their connection points scale with them.
Keep breadboard parts at **100 %**, or their pins stop lining up with the holes. Rotating a part (Ctrl+R) also
rotates its pins. For the relay and diodes, a second version is provided so the text stays upright.

## Notes on the parts

- **Breadboard (half size, 30 columns):** + and − rails at the top and bottom. In each column, rows a–e are
  connected and rows f–j are connected. Every hole is a connection point.
- **Push button:** straddles the channel. Each pin is always linked to the pin opposite it (dashed line).
  Pressing links the left pair to the right pair.
- **Relay HK4100F-DC5V-SHG:** 1 = NO, 2 = NC, 3–4 = coil (120 Ω, no polarity), 5–6 = COM (linked).
  Source: HKE datasheet plus the LCSC C12072 footprint. Check NO/NC with a multimeter.
- **Transistors:** the E-B-C order varies between parts, so check your datasheet.

## Regenerate / add parts

The library and the demo are generated by `gen_lib.py` (plain Python 3, no dependencies):

```sh
python3 gen_lib.py
/Applications/draw.io.app/Contents/MacOS/draw.io -x -f png -s 1.5 -o demo-relay-led.png demo-relay-led.drawio
```

To add a part, write a function that returns `part(title, w, h, svg_body, pins, label)`, with the pins as
`(x, y)` positions on the 20 px pitch, and call it in the *build library* section.
